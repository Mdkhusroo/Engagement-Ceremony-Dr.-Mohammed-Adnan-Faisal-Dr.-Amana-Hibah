# Engagement Invitation Website

## Files
- `index.html` — invitation page
- `style.css` — responsive royal invitation styling
- `script.js` — opening screen + countdown
- `reference.jpg` — original invitation image for reference

## Run in VS Code
1. Open this folder in VS Code.
2. Open `index.html`.
3. Use the **Live Server** extension, or simply open the HTML file in a browser.
4. Edit names, venue, date, or other text directly in `index.html`.

## Notes
- The invitation is responsive for mobile, tablet and desktop.
- The Google Maps button searches for Metro Palace Function Hall near Rafiq Chowk, Ring Road, Kalaburagi.
- The countdown is set for 2 September 2026 at 8:00 PM IST.
